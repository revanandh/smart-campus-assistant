# Smart Campus Assistant

A responsive Smart Campus Assistant for students to quickly access campus information, search services, view announcements, find events, and get simple AI-style answers.

## Features
- Campus dashboard with quick actions
- Searchable campus services and facilities
- Announcements and events
- FAQ/assistant chat interface
- Student-friendly responsive UI
- No backend required for the demo

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Project structure
- `index.html` — application UI
- `style.css` — responsive styling
- `script.js` — search, chat, announcements and events logic

## Future upgrades
Connect a real backend/database, authentication, maps, timetable APIs, college ERP data, and an LLM API for production use.
